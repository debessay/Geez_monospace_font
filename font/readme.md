
# Monospace Font (Fixed-Width Font)

## What It Means
**monospace font** (also called fixed-width or non-proportional font) is a typeface where **every character occupies exactly the same amount of horizontal space**.

- The letter `i` takes the same width as the letter `W`
- A space takes the same width as a number or symbol
- Everything lines up perfectly in vertical columns

This is the opposite of **proportional fonts** , where characters have different widths based on their shape.

## Simple Visual Comparison

| Font Type     | Example Text          | Alignment         |
|---------------|-----------------------|-------------------|
| Proportional  | iiiiii WWWWWW         | Uneven            |
| Monospace     | `iiiiii` `WWWWWW`     | Perfectly aligned |

## Main Purposes & Uses
- Code / programming – so columns and indentation line up cleanly
- Terminals / command lines
- Tables or aligned data
- ASCII art

## Advantages
- Perfect character alignment
- Excellent for reading and writing code
- Makes structure and spacing very clear

## Disadvantages
- Looks less natural and less elegant for long paragraphs of normal text
- Takes more horizontal space than proportional fonts
- Can feel “technical” or cold in regular documents

---

**In short**: Monospace fonts sacrifice beauty for precision — that’s why developers and technical users love them.
